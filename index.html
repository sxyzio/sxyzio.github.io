GitHub 文档库

文件夹、文章与文件都存放在你的 GitHub 仓库里
输入令牌，由 GitHub 核实身份后进入

令牌只会在本浏览器标签页内直接发往 api.github.com，不写入硬盘、不经过任何第三方服务；关闭标签页即清除。

怎么建仓库、怎么生成令牌

1. 建仓库：github.com/new → 名字随意（如 doc-vault）→ 私有或公开都可以，私有更安全。

2. 生成令牌：github.com/settings/personal-access-tokens → Generate new token → 选 Fine-grained。

3. Repository access 选 Only select repositories 并勾上这个仓库；Permissions 里把 Contents 设为 Read and write（只想浏览就选 Read-only）。

4. 生成后复制 github_pat_ 开头整串粘贴到上面。令牌等同于密码，不要发到群里或截图外传。
